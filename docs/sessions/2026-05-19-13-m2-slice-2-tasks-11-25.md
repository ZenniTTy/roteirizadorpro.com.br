## Decisions Made

1. **Renamed `StopsController.update` to `updateStop`** — forced by Riverpod 3's inherited `$AsyncNotifier.update(callback)` method. Memory entry captures the gotcha.
2. **Callback-injection pattern for navigation in all 7 screens that call `context.go(...)`** (`HomeEmptyPage.onAddPressed`, `AddStopPage.onSaved`, `StopDetailPage.onDeleted/onEditPressed`, `EditStopPage.onSaved`, `VoiceCapturePage.onConfirmed`, `OcrCapturePage.onConfirmed`, `AddStopsMapPage.onConfirmed`). Production defaults match the plan; tests inject stubs and avoid standing up GoRouter.
3. **`Stop.isGeocoded` helper landed in Task 19** to close the Null Island contract (`lat=0, lng=0` sentinel from manual / voice / OCR captures). Task 22 (`MapStopsPage`) filters via the helper. Task 28 (`external_nav`) is the remaining consumer — must guard before sub-2d ships.
4. **Address-only `StopForm`** instead of the plan's lat/lng inputs — the prototype confirms riders type addresses, not coordinates. Slice 3 will wire Nominatim through `/geocode` to convert label → coords.
5. **Refactor at natural boundaries.** Two cross-cutting DRY commits at the end of natural sub-slice boundaries:
   - Sub 2c done → `FakeStopsRepository` (eliminates 6-copy fake) + `stopsAsyncView` (eliminates 5-copy loading/error).
   - Sub 2b about to start → `FakeAppPermissions` (pre-emptive, before Tasks 24 + 25 added the 3rd / 4th copy).
6. **Unified StopDetailPage error copy** to "suas paradas" during the `stopsAsyncView` extraction. Tiny UX standardization not previously approved; recorded here for visibility.
7. **Combined spec + code-quality reviews on trivial tasks** (12, 18, 19, 20, 21, 23, 24, 25). Deviation from the subagent-driven-development skill's prescribed two-stage review. Justification: tasks ≤ 50 LOC where the spec compliance is mechanically derivable from the implementer's diff stat + analyzer + test counts. Full two-stage review used on tasks with substantive design surface (11, 14, 15, 22).
8. **`/stops/:id/edit`, `/stops/reorder`, `/stops/map`, `/stops/add-map`, `/stops/voice`, `/stops/ocr`** declared BEFORE `/stops/:id` in `app.dart`. Required because GoRouter matches in declaration order and would otherwise capture `edit` / `reorder` / etc. as the `:id` path param.
