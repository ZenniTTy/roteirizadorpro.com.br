# Session: Reutilizar Paradas (Área 2.5) e Tela Ativa da Rota (Área 3)

**Date:** 2026-05-28
**Topic:** slice-2-area-25-3-map

## Summary

Implementação da Área 2.5 (Reutilizar Paradas) e Área 3 (Tela Ativa com Mapa) do Slice 2. O usuário relatou problemas de persistência visual ("Remember me não está aparecendo") que se originaram da falta de hot-restart na sessão anterior.

## Decisions & Accepted Debt

- **`Route` Model Collision:** Ao usar `flutter_map` e outros pacotes, `Route` do domínio conflitou com `Route<dynamic>` do Flutter. Foi adotado o padrão `import '../../domain/route.dart' as rp_route;` em `app_drawer.dart`.
- **`RoutesProvider` Mutável:** Como a Área 2.5 e 3 exigem ações de excluir e duplicar (mesmo sendo um mock local), o `RoutesProvider` no arquivo `routes_provider.dart` foi convertido de uma função genérica (que apenas retorna uma lista constante) para uma classe herdando de `_$Routes` para suportar mutabilidade (`Notifier`).
- **MapLayer Substituição:** A `ColoredBox` temporária em `route_shell_page.dart` foi substituída pelo `FlutterMap` com `TileLayer` usando OpenStreetMap per ADR-0016. `RichAttributionWidget` foi configurado e adicionado.

## Lessons Learned

- **Hot Restart Mandatory:** Agentes em sessões diferentes frequentemente assumem que os testes do usuário incluem o build atualizado. Quando a UI não atualiza no dispositivo do usuário, o agente deve orientar explicitly sobre a necessidade de `hot-restart` ou fechar/abrir o app se a DTD não estiver conectada.
